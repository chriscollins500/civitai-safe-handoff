Quick start

Send and pick up a file.

Open SAFE Handoff on Civitai. Keep both browser tabs open while you exchange the offer and reply and finish the save.

SendPick upExpiry and privacyModel pins

Send the file

  1. Choose files and recipients.Enter one name per line. Use Prepare handoff to fingerprint the file or build a ZIP in your browser.
  2. Create a separate offer for each person.Use Copy pickup link where available. Otherwise select the offer code and send it in private Civitai chat. Send each line as its own message if the code is split.
  3. Paste the reply under the matching recipient.Choose Connect recipient. Keep the tab open until their receipt arrives.

Pick up and verify the save

  1. Open the link or paste the offer.Choose Create pickup reply. Send your reply in private Civitai chat and wait for the sender to connect.
  2. Save the file.Choose Save file and wait for the browser download to finish.
  3. Select the finished download.Use Verify saved file. The app checks SHA-256 and the sender confirms the receipt. If a large save was refused, use Get a fresh copy while the sender is still connected.

Expiry and privacy

The expiry clock starts when the handoff is ready. At 24 hours, or immediately after every required recipient verifies a save, the app closes pickup access and releases its temporary file data. You can also use Close handoff to end it sooner.

A suspended tab clears expired data as soon as it next runs. The app checks the deadline before it sends, saves, or accepts a receipt. Closing the sender tab ends the handoff.

A save that the browser already started may finish after expiry. Saved copies remain on each device. Chat messages and any copies of the offer outside the app remain where they were shared, with expired offers unable to start new pickups.

Anyone holding a valid offer can create its reply. Use one private chat per recipient and connect only the reply you expected. Recipient names are labels you enter for your receipts.

Pin models for a creator handoff

Use Choose checkpoint or Choose LoRAs to select catalog resources. Choose an exact file when a version offers several. Save the dependency JSON and include it with your workflow or share the pins in the same private chat.

Each collaborator accesses the dependencies through Civitai with their own account and entitlements.
