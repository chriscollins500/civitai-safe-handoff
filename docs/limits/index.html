Compatibility

Know what can travel.

Civitai’s save bridge accepts specific file types. Both browsers also need a direct network route.

File limits

Civitai save formats supported by SAFE Handoff
FileMaximumDetails
ZIP256 MiBAllowed archive entries only. Build one ZIP from up to 25 files.
GLB, FBX100 MiBValid binary 3D model files.
JSON, TXT50 MiBPlain text and valid JSON.
PNG, JPEG, WebP50 MiBThe extension must match the image format.

ZIP members follow the Civitai save validator. The app checks names, formats and archive size before sending. For published model weights, share model pins so collaborators can retrieve files through Civitai.

Direct network required

Files move over a WebRTC data channel between the two active browsers. The app configures host candidates and has no relay. A shared network is the best place to start. Some networks and browser privacy settings prevent a direct connection.

If the connection stops

Keep the sender tab open. Create a fresh offer for the affected recipient and repeat the exchange while the handoff is active.

What the browser tests covered

Chrome, Edge and Firefox were exercised on Windows using real browsers and an opaque, sandboxed fixture for the Civitai host. Chrome-to-Firefox testing used separate browser processes. The test saved bytes to disk and verified their digest.

The release uses Civitai’s host save contract. Step-by-step live qualification on the published candidate depends on Civitai review and access to the App Store. See the review kit for exact build hashes and test scope.
