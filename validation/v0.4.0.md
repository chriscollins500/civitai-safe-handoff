# v0.4.0 candidate evidence

The test harness runs real browsers and an opaque `allow-scripts` iframe using Civitai.com and Civitai.red host fixtures. It checks actual saved disk files. Civitai production still serves [v0.2.0](evidence/civitai-only/v0.2.0-live-deployment.json).

| Case | Observation |
| --- | --- |
| Direct interruption | Edge resumed an 8 MiB ZIP at 2 MiB and sent the remaining 6 MiB. The v0.3.0 control resent all 8 MiB after the same interruption. Firefox reproduced the comparison at 390 pixels. [Edge](evidence/civitai-only/v0.4.0-resume-edge-8mib.json) · [Firefox](evidence/civitai-only/v0.4.0-resume-firefox-8mib.json) |
| ZIP boundary | Edge resumed a 256 MiB ZIP at 64 MiB received and sent 192 MiB. The disk SHA-256 matched. A modified resume reply was refused before resending payload. [Boundary run](evidence/civitai-only/v0.4.0-resume-edge-256mib.json) |
| Receipt and archive | Edge verified 20 distinct recipient saves. The preview showed names and sizes for the accepted ZIP entries, and the combined export contained only verified recipients. [Recipient count](evidence/civitai-only/v0.4.0-capacity-edge.json) · [Archive](evidence/civitai-only/v0.4.0-archive-edge.json) · [Receipts](evidence/civitai-only/v0.4.0-receipts-edge.json) |
| Cutoff and compatibility | The full suite checked deadline enforcement, revocation, legacy v0.2.0 peers, explicit discard, and recipient isolation. [Test summary](evidence/civitai-only/v0.4.0-validation.json) |

The 256 MiB result describes the local host fixture. The signed-in, separate-device checks and the 8 GiB offline acceptance test remain open. The latter requires a native Civitai storage API with recipient grants and automatic payload deletion.

## Reproduce

```powershell
npm ci
npm run check
npm test
npm run build:civitai
npm run test:browser
npm run test:site
civitai app validate dist/civitai-app
civitai app submit dist/civitai-app --package-only --out dist/civitai-safe-handoff-0.4.0-candidate.zip
Get-FileHash -Algorithm SHA256 -LiteralPath dist/civitai-safe-handoff-0.4.0-candidate.zip
```

Use Node 26.13 or newer and Civitai CLI 0.1.150. The paired test uses the archived v0.3.0 control ZIP when available in `dist/`. Run the case named **a fresh offer resumes** with `SAFE_CIVITAI_RESUME_BOUNDARY=1` to exercise the 256 MiB candidate.
