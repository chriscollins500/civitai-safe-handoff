# Contributing

Use a small synthetic file to reproduce an issue. Record the app version, browser, Civitai domain and which part of the pickup or receipt flow you were using. Use `npm run check`, `npm run build:civitai` and the applicable browser test before opening a change. Preserve both Civitai parent origins, zero end-user installs, and the browser-only transfer path.

Keep credentials, private files and pickup codes out of sample data and screenshots. The website lives in `docs/` and the GitHub Wiki source in `wiki-source/`.
