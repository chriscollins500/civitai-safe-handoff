# Security and privacy

Each pickup offer is a short-lived capability. Share it privately and redact it from screenshots, logs, and bug reports. A receipt means the recipient’s app verified a selected disk file against its expected SHA-256. The sender uses the chat exchange to match receipt labels to people.

Please report a security concern through the repository’s private vulnerability reporting form under **Security**. Include the candidate version, browser and domain, and steps with synthetic files. Avoid including live offers, authentication data, or private Civitai files.
